### Technical decisions

- Raw SQL notification insertion supplies `randomUUID()` because Prisma’s schema-level UUID default is generated by the Prisma client and does not apply to direct SQL statements.
- Ticket deletion uses the same `ADMIN` authorization policy as ticket creation and editing. This is restrictive, predictable, and consistent with the existing MVP role model.
- Workspace deletion was not added because no workspace-deletion product/API contract exists. The temporary E2E workspace and accounts remain in the local test database; the E2E ticket itself was deleted successfully.
